# 🏦 SQL: Análise de Dados e Simulação Financeira

Este repositório é um laboratório prático focado em exploração, transformação e análise de dados utilizando **SQL** e **Python**. 

Os scripts aqui presentes foram desenvolvidos sobre um banco de dados relacional que simula o ecossistema de uma instituição financeira (com tabelas de clientes, transações, limites de crédito e chamados de atendimento). O objetivo é resolver problemas reais de negócio através de consultas otimizadas e pipelines de dados.

## 🎯 Foco das Consultas
As *queries* e scripts deste repositório não são apenas extrações simples, mas sim simulações de demandas corporativas comuns em áreas de Risco, Fraude, Relacionamento (CRM) e Operações, englobando:

* **Agregações:** Mapeamento de comportamento de clientes e faturamento temporal.
* **Cruzamento de Dados (JOINs):** Integração de múltiplas tabelas sem perda de performance ou duplicação de dados (produto cartesiano).
* **Limpeza e Tratamento (ETL):** Identificação e tratamento de valores nulos e estruturação de bases para análises futuras.
* **Lógica Condicional:** Criação de métricas personalizadas (como taxas de aprovação/recusa e limites de crédito) direto no motor do banco de dados.

## 🛠️ Tecnologias Utilizadas
* **SQL (SQLite):** Construção das consultas estruturadas, CTEs (Common Table Expressions), Window Functions e modelagem de dados.
* **Python (Pandas):** Conexão com o banco, limpeza profunda de dados (ETL) e manipulação de *DataFrames*.
